## 编写与使用说明

- 解答尽量使用对应章节及此前学过的知识，面向已学过数学分析和高等代数的读者。
- 各题以“题目”“解答”为基本结构；需要时增加“分析”或“说明”。除题目另有要求外，接受隐式解。
- 若发现题干、计算或论证有误，欢迎在仓库的 Issues 中指出具体题号和问题。
- 本仓库只发布解答，参考书目可自行前往Zlibrary下载。同时请结合所持教材核对题目。
- 若有其他问题或紧急事项，或本答案对您的合法权益构成了侵犯，请您联系 1102329175@qq.com。
- 本仓库答案后续可能更新一至两次，主要会更新部分答案的表述或降一下 AI 味等，不会大改。具体更新时间看我心情。

如需自行编译源码，可使用 XeLaTeX；字体及 `ctex`、`amsmath`、`tcolorbox` 等宏包需要由本地 TeX 发行版提供。
